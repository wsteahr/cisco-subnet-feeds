# Webex Calling Subnets

Unofficial, auto-updating mirror of the **"IP Subnets for Webex Calling
services"** table (Section 1: Call Signaling, Media, NTP & CScan) from
Cisco's official documentation:

https://help.webex.com/en-us/article/b2exve/Port-Reference-Information-for-Webex-Calling

This is **not affiliated with or endorsed by Cisco**. It's a convenience
mirror for firewall administrators who want to subscribe to this list as
an External Dynamic List (EDL) instead of manually copying it from the
help page. Always verify against Cisco's page if accuracy is critical —
Cisco's original source is authoritative.

## Caching note

`raw.githubusercontent.com` is served through GitHub's CDN and typically
caches content for a few minutes. If your firewall polls very
frequently, you may occasionally get a slightly stale copy for a short
window after an update — this is rarely an issue for infrequently
changing infrastructure lists like this one.
